# belgr-mj-anvil

`belgr-mj-anvil` registers the bundled Anvil ACP adapter used by Belgr's
Android build.

This crate is a platform integration component, not a standalone Anvil
distribution. Its Rust crate name is `mj_anvil`, and its API currently follows
Belgr's release cycle rather than a separate stability guarantee.

For installation and user documentation, see the
[Belgr repository](https://github.com/foundev/belgr).
