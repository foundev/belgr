# belgr-mj-anvil

`belgr-mj-anvil` registers the Anvil ACP adapter, one of Belgr's platform
routes alongside Draupnir.

This crate is a platform integration component, not a standalone Anvil
distribution. Its Rust crate name is `mj_anvil`, and its API currently
follows Belgr's release cycle rather than a separate stability guarantee.

For installation and user documentation, see the
[Belgr repository](https://github.com/foundev/belgr).
