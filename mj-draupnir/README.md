# belgr-mj-draupnir

`belgr-mj-draupnir` registers the bundled Draupnir ACP adapter used by Belgr's
Android build.

This crate is a platform integration component, not a standalone Draupnir
distribution. Its Rust crate name is `mj_draupnir`, and its API currently
follows Belgr's release cycle rather than a separate stability guarantee.

For installation and user documentation, see the
[Belgr repository](https://github.com/foundev/belgr).
