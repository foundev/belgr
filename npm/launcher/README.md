# Belgr

Belgr is the self-hosted power frontend for Codex and other ACP agents.

```sh
npm install -g belgr
mj
```

For a one-shot run, use `npx -y belgr`. The package installs the
native release bundle for the current platform; it does not download Belgr at
first launch. See https://github.com/foundev/belgr for supported platforms,
updates, and alternatives.
